# Clients

One folder per cohort organisation: what Sangam is doing **for that NGO** — which funders have
been researched on their behalf, what the evidence says, what is missing, and what would change
their position most.

These are not org profiles. The profile of an organisation is data, and it belongs in the
catalog. This is the read on top of it: fit, evidence quality, eligibility gaps, and the next
actions that follow.

Two conventions, both borrowed from the hand-vetting sheets these files summarise:

- **Every claim traces to a source** — a fact-check sheet, seeded data, or a dated Sangam Import
  run. Where a figure is absent the file says *not recorded*, which means nobody has entered it,
  never that the thing does not exist.
- **A score is not a relationship.** Fit and recency are different questions, and a file that
  reports one without the other is misleading.
