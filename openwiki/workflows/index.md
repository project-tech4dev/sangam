# Files

- [One Ask Turn, End to End](ask-turn.md) - Traces one Ask Sangam question from the browser through the Next.js chat proxy, backend auth and thread ownership, the AG-UI /agent endpoint, the deep-agent loop, the four SQL layers (run as the caller under RLS), citation markers, the post-answer audit, tracing and checkpointing, with each failure path (retry budget, validator rejection, 5 s timeout, 50-row cap, non-blocking audit caveat).
- [Deploying by Hand](deploying-by-hand.md) - How to deploy Sangam, which only happens when someone runs the Deploy GitHub Actions workflow by hand. Covers what the workflow does and diffs, how to order a deploy with migrations, the 1800 s function limits, and the checks to run afterwards.
- [One Import Turn: choose_sources to Undo](import-turn.md) - End-to-end trace of a Sangam Import (Scout) turn. It runs from the choose_sources pause through research, save_research refusals, brief publish, the Review save transaction and promote, to staff undo. It lists the refusal points, the pauses, the fact end-states and the unfinished work.
- [One proposal, end to end](proposal-lifecycle.md) - Trace of one grant proposal in Sangam Pitch, enabled for everyone alongside RFP Watch (the Coming soon set is empty), from "Start a proposal" on a Funder Match card through the four steps, file readers, questions, section writing, the readiness review, checked language smoothing and the Word download with versions. It covers PATCH /work with section rev, per-editor chat threads, and what code refuses at each step.
- [Writing and Applying a Migration](writing-a-migration.md) - Step-by-step for adding a schema change in db/migrations/ - file naming, transaction and checksum rules, RLS and grants for new tables, the separate SQL-catalog decision, and applying locally and then to staging after a backup.
